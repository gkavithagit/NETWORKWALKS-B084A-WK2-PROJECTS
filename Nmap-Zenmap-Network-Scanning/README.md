# Nmap and Zenmap Network Scanning

This project demonstrates basic network scanning using Nmap and Zenmap in Kali Linux.

## Tools Used
- Nmap
- Zenmap
- Kali Linux

## Target
127.0.0.1 (Localhost)

## Activities
- Nmap version verification
- Service version detection
- Fast port scanning
- Saving scan results
- GUI-based scanning using Zenmap
