📌 About This Repository

This repository contains my Week 2 cybersecurity practical projects completed using Kali Linux.

🎯 Projects Included

1. W2-PM4 – Footprinting Using theHarvester

Tool: theHarvester
Platform: Kali Linux
Target: example.com
Data Source: crt.sh

Project Description:

This project demonstrates the basic use of theHarvester, an open-source tool used for gathering publicly available information about a target domain.

The tool was executed using the crt.sh data source to understand the process of domain footprinting and information gathering.

Activities Performed:

- Verified theHarvester installation.
- Explored tool commands and options.
- Executed a footprinting command.
- Generated JSON and XML output reports.
- Examined the generated report files.

Results:

JSON and XML report files were successfully generated. The selected example.com test produced no host findings in the generated results.

2. W2-PM5 – Network Scanning Using Nmap and Zenmap

Tools: Nmap and Zenmap
Platform: Kali Linux
Nmap Version: 7.99
Target: 127.0.0.1 (Localhost)

Project Description:

This project demonstrates basic network scanning and service detection using Nmap and Zenmap.

Nmap was used through the command-line interface to perform scanning activities, while Zenmap provided a graphical interface to execute and examine scan results.

Activities Performed:

- Verified Nmap installation and version.
- Identified network interfaces.
- Performed service version detection.
- Executed fast port scanning.
- Saved scan results in a text file.
- Performed graphical scanning using Zenmap.
- Organized screenshots and scan output files.

Results:

The localhost target was identified as active.

The scan reported 1000 TCP ports as closed, with no open TCP ports reported in the saved output.

The scan results were successfully saved in a text file.
